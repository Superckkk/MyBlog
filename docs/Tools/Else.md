# 其它在线工具

一些不用装、打开就能用的站点。按用途分了一下。

## 配色

- [ColorSite](https://colorsite.librian.net/) —— 配色方案参考，找色卡用

## 画图

- [Excalidraw](https://excalidraw.com/) —— 手写风格的白板，画架构图和示意图很快，
  出来的效果比正经绘图软件松弛，适合放博客里

## 图标

- [Icones](https://icones.netlify.app/) —— 图标聚合搜索，一个入口查几十个图标集
- [Lucide](https://lucide.dev/icons/) —— 线条风格图标库，风格统一，开源
- [Morphicons](https://www.morphicons.com/) —— 自带动效的图标库，适合做交互反馈

## Typst 相关

- [Detexify for Typst](https://detypify.quarticcat.com/) —— 手写一个符号，帮你找出对应的
  Typst 符号名。等价于 LaTeX 圈的 Detexify，写公式时很省事
