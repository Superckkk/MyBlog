## 这个站点

用 [MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) 搭的，
内容全是 Markdown，`mkdocs build` 出来是一堆静态文件，扔哪儿都能跑。

正文字体用的是[霞鹜文楷](https://github.com/lxgw/LxgwWenKai)，字体文件自托管，
不依赖外部 CDN。
